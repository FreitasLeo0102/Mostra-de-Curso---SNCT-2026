# 🖥️ Mostra de Curso — Técnico em Informática

Site desenvolvido para a **Mostra de Curso do Instituto Federal do Triângulo Mineiro (IFTM) — Campus Patrocínio**, realizada durante a **Semana Nacional de Ciência e Tecnologia (SNCT)**.

O projeto tem como objetivo apresentar o curso Técnico em Informática, seus projetos, atividades e visitas técnicas, permitindo que os visitantes conheçam um pouco mais da formação oferecida pelo campus.

## ✨ Funcionalidades

- **Apresentação do curso:** informações sobre o curso Técnico em Informática.
- **Projetos:** exposição de projetos desenvolvidos pelos estudantes.
- **Visitas técnicas:** registros de experiências e visitas realizadas durante a formação.
- **Interface interativa:** navegação entre as seções em uma interface inspirada em sistemas e elementos visuais retrô.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎨 Identidade visual

O site utiliza uma estética inspirada em interfaces retrô e pixel art, com elementos visuais que remetem aos computadores e sistemas antigos, trazendo uma identidade visual relacionada à área da Informática.

## 🎓 Contexto do projeto

A Semana Nacional de Ciência e Tecnologia (SNCT) é um evento dedicado à divulgação científica e tecnológica. Nesse contexto, a Mostra de Curso é uma oportunidade de apresentar à comunidade as atividades desenvolvidas pelos estudantes e as possibilidades de formação oferecidas pelo IFTM Campus Patrocínio.

Este site foi desenvolvido especialmente para esse evento, reunindo informações e registros do curso em um único espaço digital.

## 👨‍💻 Desenvolvimento

Projeto desenvolvido para a Mostra de Curso do Técnico em Informática do **IFTM — Campus Patrocínio**.
